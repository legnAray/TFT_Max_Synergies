# 云顶之弈 / 金铲铲之战 · 最大羁绊计算器

[English](README.md) | [简体中文](README.zh-CN.md)

给定人口（6~10），从当前赛季棋子池中找出**羁绊价值最大**的阵容，支持丰富的约束（必带/屏蔽
棋子、屏蔽/固定羁绊、纹章）与两种评分模式。求解采用**整数规划**（glpk.js / GLPK WASM），
结果为**精确最优**，非启发式。思路同 [tactics.tools 的 perfect-synergies](https://tactics.tools/zh/perfect-synergies)，
但做了通用化扩展。

![Web 界面](figs/fig1.png)

当前数据：**S18「Enchanted Wilds / 魔法荒野」**（来源
[CommunityDragon](https://raw.communitydragon.org/latest/cdragon/tft/zh_cn.json)，中文国服命名）。

## 功能特性

- **双评分模式**（可切换）：*羁绊质量*（默认——每踩一个断点记 1 档，第 2 档计 2 分）与
  *羁绊数量*（不同名激活羁绊各计 1，踩几档都只算 1 个）。
- **约束体系**：必带棋子（锁定后优化剩余）· 屏蔽任意棋子 · 一键屏蔽全部 5 费 ·
  **硬屏蔽羁绊**（该羁绊不许激活）· **固定羁绊至少 N 档**。
- **纹章**（≤10 个）：固定计入羁绊计数，不指定携带者。
- **多套解**：每档 5 套（默认）或 10 套，按分数降序、同分按队伍总费用**从贵到便宜**排序。
- **赛季机制建模**：形态互斥组（拉克丝）、进化型棋子（卡兹克）、多格/多计数棋子
  （远古巨龙）、简化特殊羁绊（宿敌）——全部在各赛季规则文件里声明，编译成与赛季无关的数据。
- **三端同核**：Web 界面、CLI、HTTP API 共用同一求解核心。
- **一条命令换赛季**：提取流水线自动下载 CommunityDragon 数据并编译（含特殊棋子规则）。

## 快速开始

```bash
npm install
npm run serve          # Web 界面 http://localhost:8080
```

```bash
node cli.js                       # CLI：6-10人口，每档 5 套
node cli.js --levels 8 --topk 10  # 多要几套
node cli.js --json                # 输出 JSON（机器可读）
```

S18 结果参考（18.3 版本数据，卡兹克进化满级）：6人口 12 档 · 7人口 13 档 · 8人口 15 档 ·
9人口 17 档 · 10人口 18 档（未进化约低 2 档）。

## Web 界面

打开 http://localhost:8080（`npm run serve` 或 `node server.js [--port 8080]`，也支持 `PORT`
环境变量）。`server.js` 是零依赖的 Node HTTP 服务，`/api/solve` 直接复用 `lib/solve.js`，
结果与 CLI 完全一致。

控制区（所有选择器点击即展开完整下拉列表，不打字也能直接选，输入仍可筛选）：

- **赛季**：下拉自动发现 `data/` 里的所有 `s{N}.json`，新提取的赛季无需改代码即出现。
- **特殊机制**：由数据自动生成。S18 为：*禁用拉克丝* / *禁用卡兹克* 开关（整组互斥家族）
  与 *卡兹克进化* 次数上限（默认 / ≤2 / ≤1 / 不进化），用于对局中期推演。
- **人口档**（可多选）· **每档解数**（5/10）· **评分模式** · **屏蔽全部 5 费**。
- **必带棋子** · **纹章**（按羁绊叠加，x/10 计数）· **固定羁绊**（chip 上调档位）·
  **屏蔽棋子** · **屏蔽羁绊**。

结果渲染为按费用配色的棋子标签 + 逐羁绊明细：断点命中高亮、档位徽章、精确计数规则备注、
浪费提示、纹章贡献与未激活羁绊。冲突选择（屏蔽/固定/纹章/必带之间）自动解除。注意：人口
越高求解越慢（S18 数据下 10 人口 30 秒起步），各档独立请求、算完即渲染；约束过强时返回
"无可行解"而不是错误结果。

## CLI

```bash
node cli.js [--set 18] [--levels 6-10|6,7,8 | --level 9] [--topk 5] [--json] [--mode tiers|count]
            [--units 名1,名2 --level 9]            # 必带棋子
            [--emblem 地狱火,地狱火,法师]           # 纹章，总数 ≤10
            [--ban-unit 远古巨龙,魔像] [--ban-5cost]
            [--ban-trait 法师,护卫]                 # 硬屏蔽羁绊
            [--pin 月蚀骑士=3,宿敌]                 # 固定羁绊（档位可省，默认 1）
```

棋子/羁绊名用 `data/s{N}_summary.md` 里的名字；匹配先精确、后包含（忽略空格，
`拉克丝(地狱火)` 也能匹配 `拉克丝 (地狱火)`）。

## HTTP API

| 接口 | 说明 |
|---|---|
| `GET /api/sets` | 可用赛季列表（扫描 `data/`），含名称/棋子/羁绊数 |
| `GET /api/data?set=18` | 某赛季完整结构化数据 |
| `GET /api/solve?...` | 求解，参数见下表 |

`/api/solve` 参数（棋子/羁绊均支持 key 或名字，忽略空格）：

| 参数 | 含义 | 默认 |
|---|---|---|
| `set`、`level` | 赛季号、人口（1-15） | 18、必填 |
| `topk` | 返回解数 | 5 |
| `mode` | `tiers`（质量）\| `count`（数量） | `tiers` |
| `units` | 必带棋子（逗号分隔） | — |
| `emblems` | 如 `地狱火,地狱火,法师` 或 `key:2`；总数 ≤10；独有羁绊拒绝 | — |
| `banUnits` | 屏蔽棋子 | — |
| `ban5cost` | `1` 屏蔽全部 5 费 | — |
| `banTraits` | 硬屏蔽羁绊 | — |
| `pins` | 如 `月蚀骑士=3,宿敌`（档位可省，默认 1） | — |

响应含每套的棋子明细、总费用与 `constraints` 回显。非法输入返回 `400 {error}`，
中文报错（纹章超限、独有羁绊纹章、屏蔽/固定/纹章冲突、固定档位超界、名字不存在等）。

## 评分与建模

- 常规棋子：占 1 格，对自身每个羁绊 +1 计数；特殊棋子按数据 JSON 里的通用字段处理：
  `slots`（占格数）、`weights`（羁绊计数权重）、`tierRules`（某档的激活条件）、
  `groups`（互斥组，`{name, units}`）。
- 档位 = 该羁绊踩到的断点个数（断点允许重复，如游戏内宿敌的 1/1/2）。
- 整数规划：`x[棋子]∈{0,1}`，人口约束 `Σ slots·x = N`，互斥组 `Σx ≤ 1`，
  档位变量 `y[羁绊,断点]` 满足 `加权计数 ≥ 断点·y`（有激活条件的档位再加
  `计数 + M·y ≤ 条件值 + M`）；**数量模式**增加 `z[羁绊]` 指示变量
  （`y ≤ z ≤ Σy`，最大化 Σz）；纹章给羁绊加固定计数 `E`（约束变为 `Σw·x ≥ b·y − E`）；
  硬屏蔽羁绊禁止激活（`加权计数 ≤ 首断点 − 1`）；固定羁绊要求 `Σ_b y ≥ N`。
- Top-K 并列解：用"禁止重复解"约束（no-good cut）迭代枚举，按羁绊档位构成去重；
  最终按分数降序、同分队伍总费用降序排列。不可行问题按求解器状态显式判定——
  glpk.js 对无解的 MIP 仍会返回 status=`GLP_NOFEAS` 的"结果"对象，已专门处理。

## 数据更新（每个新赛季一次）

```bash
node scripts/extract.js 19        # 自动下载 CommunityDragon 数据 -> data/s19.json（+ s19_summary.md）
node scripts/extract.js 19 --refresh  # 强制重新下载原始文件
node cli.js --set 19              # 或在 Web 界面赛季下拉里直接选 S19
```

赛季数据按"**常规棋子 + 特殊棋子**"组织。常规棋子零声明：占 1 格、对自身每个羁绊 +1 计数，
断点由羁绊数据决定。特殊棋子在 `sets/s{N}.rules.js` 里声明，由提取脚本编译成数据 JSON 的
通用字段，求解器与赛季无关：

| 规则字段 | 含义 | S18 示例 |
|---|---|---|
| `exclusive`、`formTraitWeight` | 互斥组；形态羁绊（非公共羁绊）的计数权重 | 拉克丝 10 形态 |
| `slots`、`traitWeights` | 占用格数；显式羁绊计数权重 | 远古巨龙（占 2 格、峡谷野怪 +2） |
| `trait` + `tierExactCount` | 某档需要精确计数 | 宿敌（简化前） |
| `evolutions: {choices, maxEvolve, distinct}` | 合成全部进化变体为互斥棋子副本（带 `evo`/`variantOf` 元数据供前端用） | 卡兹克 15 变体 |
| `removeUnits` | 把棋子移出池子 | 雷恩加尔 |
| `traitBreakpoints` | 覆盖羁绊断点 | 宿敌 → `[1]` |
| `setName` | 赛季显示名（下拉用） | 魔法荒野 |

换赛季后建议过一遍生成的 `data/s{N}_summary.md` 核对清单，并做一次"有规则 vs 无规则"
对比，确认规则只影响预期的棋子。

## S18 特殊棋子（均在 `sets/s18.rules.js` 声明）

- **拉克丝（大元素使）**：10 个形态互为互斥组，最多上场 1 个（游戏内：拥有 1 个后商店中
  其余形态都转为同羁绊）；形态羁绊 **+2 计数**。
- **卡兹克进化**：参与击杀使其永久获得从 裁决使/迅捷射手/狂战士/法师 中选择的一项羁绊
  （最多 3 次、不重复）。建模为 15 个互斥变体棋子（进化 0-3；同 3 费、宿敌计数不变）——
  求解器自动选最优进化路线；Web 端提供每次对局的进化上限与整族禁用；对局中期可用
  `--units` 锁定具体进化状态。
- **宿敌（简化建模）**：游戏内断点为 1/1/2（单人卡兹克激活第 1+2 档）。本项目按口径简化：
  雷恩加尔（除宿敌外无羁绊、上场从不增加档位）直接移出棋子池，**宿敌按"卡兹克专属
  1 档羁绊"计**——出现卡兹克（含进化变体）即 +1 档。
- **远古巨龙**：占用 2 个弈子栏位，提供 +2 峡谷野怪计数。实测结论：6-10 任何人口的最优解
  都不含远古巨龙（2 格换 1 个保底档位，不如两个常规棋子各踩一个 2 断点羁绊）。
- 独有羁绊（宝石骑士、翠神等断点为 `[1]` 的羁绊）属于常规机制，由断点数据自动处理；
  峡谷野怪 10 档的 +人口按固定人口建模忽略。

## 跨平台（Windows / Ubuntu）

- 纯 JavaScript + WebAssembly，**零原生依赖**：`node_modules` 里没有任何平台二进制包，
  同一份目录在 Windows 与 Linux 上直接可用（已在 Ubuntu 22.04 / WSL2 + Node 24 实测）。
- 文件路径全部走 `path.join`/`__dirname`，无盘符、无反斜杠硬编码、无 `process.platform` 分支。
- 环境要求：**Node ≥ 18**（用到全局 fetch；已在 Windows + Node 24 开发验证）。
- Ubuntu：建议用 nvm 装 Node 18+（发行版自带源可能过旧），然后 `npm install && node server.js`。
- 中文输出为 UTF-8：Ubuntu 终端默认就是 UTF-8；Windows 建议用 Windows Terminal / Git Bash，
  老 cmd 代码页（cp936）下中文显示可能乱码（仅显示问题，`--json` 输出不受影响）。

## 已知边界 / 计划

- 纹章为玩家手选的固定计数；求解器自动选纹章、海克斯强化未建模。
- 尚无通用费用上限（目前只有屏蔽 5 费 / 屏蔽棋子）；可加 `--max-cost`，欢迎提需求。
- 峡谷野怪 10 档的 +人口奖励未建模。
